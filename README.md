# CPM GENIUS PRO

A gold-and-black Kivy companion app for Car Parking Multiplayer fans.

## Features
- Manual in-game money and coin record tracking
- Personal car collection
- Saved tuning notes
- Game tips
- Basic player statistics
- Local JSON persistence

This companion app does not modify the actual game, generate currency, or access game accounts.

## Build
The included GitHub Actions workflow builds a debug APK when you push to `main` or manually run the workflow from the Actions tab.

If the build fails, open the workflow run and inspect its logs. Build toolchains can change, so the workflow may need maintenance.
